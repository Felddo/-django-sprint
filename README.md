# Django Sprint

Учебный проект на веб-фреймворке **Django**, разработанный в рамках спринта.


## О проекте

Этот проект представляет собой веб-приложение, созданное для закрепления навыков работы с фреймворком Django. 

**Основные возможности:**
* Маршрутизация и обработчики запросов.
* Работа с базами данных через ORM Django.
* Шаблонизация и отрисовка динамических страниц.
* Админ-панель Django для управления контентом.


## Технологии

Проект написан на:
* **Python** 3.10+
* **Django** 4.x / 5.x
* **SQLite**
* **HTML5 / CSS3**
